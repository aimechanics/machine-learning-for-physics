# Hands-on sessions

Create one directory per practical session, for example:

```text
hands-on/
├── 01_pytorch/
├── 02_autodiff/
├── 03_physics_informed_learning/
└── ...
```

A session directory can contain:

- one main Jupyter notebook;
- helper Python files;
- a small `data/` directory when needed;
- a short session-specific `README.md` only when setup or instructions differ.

Avoid committing notebook checkpoints, generated outputs, large datasets, or large model checkpoints.
